This is your One Meaningful Game collection.

Create a cover for your One Meaningful Game.
The file must be a 640x480 24-bit RGB Windows Bitmap (.bmp) image.
You can use GIMP to convert and export any image in this format.

Place ZIP ROMs in roms/<core>/ and side games in roms/<core>/random/.
The folder name selects <core>_libretro.so from the installed RetroArch cores.
For MAME 2003-Plus, use roms/mame2003_plus/ (mame2003_plus_libretro.so).
The old mame2003 folder name is still supported.
